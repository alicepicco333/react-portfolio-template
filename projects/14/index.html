5PIC3 live at Fullfillment Music Center

An audio-reactive visual set performed live as 5PIC3 at Fullfillment Music Center, written in Hydra Video Synth in real time.

Category
Live Coding
Techniques
Live Coding, Hydra, Performance

Notes

As is usual in live coding, the code was projected together with the visuals, so the room could watch the patches being typed, changed and broken as the music moved.
